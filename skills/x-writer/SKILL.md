# X Writer

Write posts for X that sound like a sharp human, not a content bot. Optimize for the platform's reality: the first line earns the click, specificity earns the follow, and consistency earns the audience.

## When to use

- "Write a tweet/thread about...", "turn this blog post into a thread", "help me grow on X"
- Launch announcements, build-in-public updates, engagement replies

## Voice calibration (do this first)

- If the user has shared past posts or has a known style, mirror it: sentence length, capitalization habits, emoji usage, edginess level.
- Otherwise default to: plain words, short sentences, line breaks between thoughts, no hashtags, no corporate tone, at most one emoji.
- Read the draft aloud test: if it sounds like a press release or LinkedIn post, rewrite it.

## Formats

### Single post
- **Line 1 is the hook** — it must work standalone (see patterns: contrarian take, specific number/result, mistake callout, hot observation).
- Body: one idea only. Cut everything that serves a second idea.
- Strong closers: a punchline, a question, or a clean stop. Never "Thoughts?" by default.
- 280 chars is a ceiling, not a target — short posts often outperform.

### Thread
- Tweet 1 = hook + promise of the payoff ("Here's the exact playbook:"). It decides everything.
- Each tweet must stand alone when screenshotted: one idea, no orphaned "and also..." tweets.
- Use numbers/structure (1/, 2/ optional — content beats formatting).
- Final tweet: recap + single CTA (follow, link, or reply prompt — pick ONE).
- Ideal length 5-9 tweets. If the content only fills 3, write a long single post instead.

### Build-in-public update
- Lead with the number or the event ("$4,120 MRR. Up $600 this month."), then the lesson, then what's next.
- Honesty performs: include what went wrong.

### Launch post
- What it is (one line) → who it's for → the one killer capability → link. Optionally a demo GIF/video note.
- Prepare 2-3 follow-up posts for launch day (origin story, behind-the-scenes, milestone updates).

## Process

1. Get the raw material: idea, story, article, or launch details. Identify the ONE insight worth posting.
2. Ask (only if unknown): goal of the post — reach, followers, or clicks? These trade off; links depress reach, so gate links to the reply or final tweet when reach matters.
3. Draft **3 variants** with different hooks/angles for single posts; for threads, draft the full thread plus 2 alternative openers.
4. Self-edit pass: cut the first sentence if the second is stronger (it usually is); replace abstractions with specifics; remove hashtags, "I'm excited to", "game-changer", and rhetorical throat-clearing.

## Content calendar mode

When asked for ongoing content: propose a weekly mix (e.g. 2 insight posts, 1 story/lesson, 1 build-in-public, 1 engagement question, daily replies to larger accounts in niche), then generate a batch of 7-14 posts the user can edit and schedule.

## Rules

- Specific numbers, names, and moments beat abstract advice — always.
- One idea per post. One CTA per thread.
- Never fabricate metrics, stories, or results; ask the user for the real ones.
- Punctuation-perfect prose is optional; clarity is not.
